# Documentación de UCO Kudos

Proyecto integrador final de Diseño Orientado a Objetos, Universidad Católica de Oriente.

| Documento | Secciones del enunciado que cubre |
|---|---|
| [01_ANALISIS.md](01_ANALISIS.md) | Introducción, contexto, objetivos, actores, requisitos, decisiones de análisis |
| [02_REGLAS_DE_NEGOCIO.md](02_REGLAS_DE_NEGOCIO.md) | Las 250 reglas y dónde se garantiza cada una |
| [03_MODELOS.md](03_MODELOS.md) | Modelo anémico, modelo enriquecido, eventos por tipo, políticas por tipo, modelo de dominio |
| [04_UML.md](04_UML.md) | Casos de uso, clases, secuencia, actividad y estado |
| [05_DATOS_Y_ARQUITECTURA.md](05_DATOS_Y_ARQUITECTURA.md) | Modelo de datos, arquitectura, patrones utilizados |
| [06_CALIDAD_Y_PRUEBAS.md](06_CALIDAD_Y_PRUEBAS.md) | Calidad del software, análisis estático, pruebas, conclusiones |
| [07_TRAZABILIDAD.md](07_TRAZABILIDAD.md) | Matriz requisitos, reglas, casos de uso, clases, componentes, pruebas |
| [MANUAL_PUESTA_A_PUNTO.md](MANUAL_PUESTA_A_PUNTO.md) | Instalación, configuración, ejecución, pruebas y despliegue |

Los diagramas están escritos en Mermaid; GitHub y Visual Studio Code con la extensión de vista previa los dibujan directamente desde el Markdown.
